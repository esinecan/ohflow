# Run notes - run {{run_id}}

The run log records what the engine did.
Only you can record what you did, and what surprised you.

Add one line each time you:

- resume, pause or kill the run;
- edit a brief or a workflow;
- fix something by hand, including a merge;
- overrule a gate;
- see a result you did not expect.

Format: `HH:MM | did or surprise | what | why`
